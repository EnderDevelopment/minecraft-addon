# Horror Addon for Minecraft Bedrock Edition

The Horror Addon is an open source project that enhances the Minecraft Bedrock Edition experience with new items and mobs inspired by horror themes. This addon includes a custom armor set, a unique mob, a powerful sword, and specialized tools designed to add a terrifying twist to your gameplay. It's perfect for players who want to add a darker, more intense atmosphere to their worlds.

## Install

1. Download the Horror Addon from the GitHub repository.
2. Extract the contents of the downloaded file.
3. Place the extracted folder into the `behavior_packs` directory of your Minecraft Bedrock Edition world.
4. Open Minecraft Bedrock Edition and select the world where you placed the addon.
5. Enable the "Horror Addon" in the world's settings.

## Use

1. Craft the Horror Armor using the provided recipes.
2. Equip the armor to gain increased protection and durability.
3. Summon the Horror Mob using the appropriate command or spawn egg.
4. Use the Horror Sword to deal significant damage to enemies.
5. Utilize the Horror Tools to efficiently mine blocks and gather resources.
